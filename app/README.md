# app

Apps that live here until they deserve a repo of their own.

| App | What it is |
|---|---|
| [`alt‑tab`](alt-tab) | A macOS window switcher that only switches windows: ⌥Tab, one Space, icons and titles. Swift, no Xcode needed, `install.sh` builds and installs it as a launchd agent. |
| [`screenshot`](screenshot) | A ⌘⇧5 replacement for macOS: the same bar and six modes, the file on disk the moment you click, pins, and an Options menu that saves to several folders at once. Swift, no Xcode needed, `install.sh` builds and installs it as a launchd agent. |
