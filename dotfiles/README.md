# dotfiles

| File | Goes to |
|---|---|
| `ghostty/config` | `~/.config/ghostty/config` |
| `fish/config.fish`, `fish/functions/fish_prompt.fish` | `~/.config/fish/` |
| `zprofile` | `~/.zprofile` (the `PATH` as brew and the installers left it) |
| `gitconfig` | `~/.gitconfig`, then add your own `[user] email` |
| `git/ignore` | `~/.config/git/ignore` |
